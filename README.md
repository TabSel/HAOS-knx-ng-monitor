# KNX-NG-Monitor – Home Assistant App

[ingel81/knx-ng-monitor](https://github.com/ingel81/knx-ng-monitor) als HAOS App

## Voraussetzungen

- Home Assistant OS oder Supervised (Container-basiert)
- Raspberry Pi 4 mit **64-Bit** Betriebssystem (32-Bit wird vom Upstream-Projekt
  nicht unterstützt)
- Netzwerkzugriff vom Pi zu deinem KNX-IP-Interface/-Router

## Installation

1. In Home Assistant: **Einstellungen → Apps → App installieren → ⋮ → Repositories** → die URL des Repos eintragen.
2. **KNX-NG-Monitor** erscheint in der Liste → installieren.

Alles weitere unter [ingel81/knx-ng-monitor](https://github.com/ingel81/knx-ng-monitor)
